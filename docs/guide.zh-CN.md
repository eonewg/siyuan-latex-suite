## 第一次写公式

### 进入公式编辑器

在正文中键入 `mk`，创建行级公式；在空段落中键入 `dm`，创建公式块。也可以使用思源自带的公式入口。普通正文中的自定义片段不会展开，`mk` / `dm` 是专门适配的两个入口。

### 写一个带分数的表达式

1. 在公式编辑器中键入 `@a`，得到 `\alpha`。
2. 接着键入 `+x/`，得到 `\alpha+\frac{x}{}`，光标位于分母。
3. 键入 `y` 填写分母。
4. 按 `Tab` 移到分数后的停靠点，再继续输入。

自动片段在触发词完成后展开，不需要空格或 Tab。手动片段则需要按展开键；例如默认配置中，键入 `sum` 会先得到 `\sum`，再按 `Tab` 可展开带上下限的模板。展开后直接输入以替换当前停靠点的默认值。

### 查找其他片段

在“设置 → 集市 → 已下载 → Latex Suite → 设置”点击“打开片段速查”，或在思源命令面板搜索 **Latex Suite 片段速查**。

速查支持搜索触发词、说明、模板和宏范围，也可按自动、手动、选区片段筛选。它展示当前已保存的配置，不执行动态 replacement 函数；设置中尚未保存的改动不会出现在速查里。

## 快捷键与导航

### 默认键位

以下 9 项动作可以分别修改，留空可禁用对应动作：

| 动作 | 默认键 | 何时使用 |
| --- | --- | --- |
| 展开手动片段 | `Tab` | 光标前有匹配的手动触发词 |
| 下一个停靠点 | `Tab` | 模板有尚未填写的参数 |
| 上一个停靠点 | `Shift-Tab` | 返回前一个参数 |
| 向右跳出 | `Tab` | 越过右侧闭合符号，或关闭公式面板 |
| 向左跳出 | `Shift-Tab` | 回到左侧开括号前，或关闭公式面板 |
| 自动分数 | `/` | 将光标前的表达式或选区作为分子 |
| 矩阵换列 | `Tab` | 在当前可用的矩阵单元格中插入 ` & ` |
| 矩阵换行 | `Enter` | 插入行分隔符，并按环境布局处理空白 |
| 矩阵下一行末尾 / 跳出 | `Shift-Enter` | 移到下一行末尾或环境结尾 |

全局启用/停用默认使用 `Alt+Shift+L`，macOS 为 `Option+Shift+L`；也可通过“启用/停用 Latex Suite”命令操作。停用后的输入和按键会清理旧停靠点状态。

### 为什么同一个 Tab 会做不同的事

有活动停靠点时，优先在停靠点间导航，而不是插入矩阵列或跳出括号。手动片段展开也先于普通矩阵导航。若矩阵换列与向右跳出使用同一个键，插件先尝试跳出当前单元格的闭合括号，再换列。

没有其他目标时，跳出动作可以关闭公式面板。若希望只在公式开头或末尾退出，请启用“仅在公式边界退出”。再次键入右侧已有的 `)`、`]` 或 `}` 也可跳过它，受 Tab 跳出开关及闭合符号列表控制。

### 改键

在设置里填写 `Ctrl-j`、`Mod-/`、`Shift-Enter` 等格式。`Mod` 接受 Ctrl 或 Command；`Ctrl--` 表示 Ctrl 加减号。请选用当前系统和宿主未占用的键位。

每个片段的 `triggerKey` 优先于全局手动展开键。自动分数改键后，普通 `/` 保持为字面斜杠。

## 分数、矩阵与选区

### 自动分数

| 操作 | 默认结果 |
| --- | --- |
| 键入 `x/` | `\frac{x}{}`，进入分母 |
| 键入 `(a+b)/` | 将括号中的整体表达式作为分子 |
| 选中表达式后按 `/` | 将选区作为分子 |
| 键入 `//` | 插入空分数模板，先填写分子，再填写分母 |

设置中的“分数命令”默认是 `\frac`；“自动分数终止字符”决定向左扫描分子时在哪里停止。默认还排除了上标和 `\pu{}` 等区域，可通过 JSON 二元数组调整。文本宏、受限宏与注释区域不会触发自动分数。

### 矩阵与对齐公式

键入 `pmat` 或 `bmat`，分别插入 `pmatrix` 或 `bmatrix` 模板。然后：

1. 输入第一个单元格，用 `Tab` 换列。
2. 用 `Enter` 创建下一行。
3. 用 `Shift+Enter` 导航到下一行末尾或环境结尾；它不会插入新行。

例如，在 `bmat` 模板中依次输入 `a`、Tab、`b`、Enter、`c`、Tab、`d`，可以填写一个 2 × 2 矩阵。

单行环境用空格衔接 `\\`，多行环境保留缩进。默认识别 `pmatrix`、`bmatrix`、`Bmatrix`、`vmatrix`、`Vmatrix`、`matrix`、`array`、`cases`、`align`、`aligned`、`gather`，以及 `eqalign` 宏，可在设置中调整。

在分数参数、文本宏、颜色参数或注释中，矩阵快捷键可能不会插入列分隔符；先移回单元格的数学内容处再操作。

### 选区变换与括号

选中表达式后，按以下默认单键进行变换：

| 键 | 模板命令 |
| --- | --- |
| `U` | `\underbrace` |
| `O` | `\overbrace` |
| `C` | `\cancel` |
| `K` | `\cancelto` |
| `B` | `\underset` |

这些键位区分大写，请按 Shift 加对应字母。需要注释或参数时，展开后填写停靠点。也可自定义含 `${VISUAL}` 的选区模板。

“自动放大括号”会在片段含 `\frac`、`\sum`、`\int` 等指定命令时加入 `\left` / `\right`。触发命令及括号内侧空格均可调整。

## 自定义片段

### 编辑位置与格式

打开插件设置，编辑 **Snippets（Latex Suite JavaScript 格式）**。这里保存的是完整片段数组；添加规则时，请把条目放进现有数组，保留需要继续使用的内置规则。修改前可以把两个源文本框的内容复制到自己的备份文件。

片段和变量都是受信任的 JavaScript 表达式，支持注释、正则字面量和函数。只使用自己理解并信任的配置。普通片段数组和表达式 `export default [...]` 均可；变量使用对象或 `export default {...}`。不支持完整模块、`import` 或 `require("latex-suite")`。

### 可直接尝试的规则

以下数组可用作独立配置，也可逐条加入已有数组。`frac` 和 `same` 是此处新增的示例触发词：

```js
[
  // 自动片段：@q → \quad
  {trigger: "@q", replacement: "\\quad", options: "mA"},

  // 手动片段：frac + Tab，依次填写分子、分母、公式后的位置
  {trigger: "frac", replacement: "\\frac{$0}{$1}$2", options: "m"},

  // 默认值与联动：修改第一个 x，另一个 x 跟随变化（原生源码框）
  {trigger: "same", replacement: "${0:x}+${0:x}$1", options: "m"},

  // 正则：xnorm → \lVert x \rVert
  {
    trigger: /([A-Za-z])norm/,
    replacement: "\\lVert [[0]] \\rVert$0",
    options: "mrA"
  },

  // 选区：选中表达式后按 U
  {trigger: "U", replacement: "\\underbrace{${VISUAL}}_{$0}$1", options: "mv"},

  // 仅快捷键：公式编辑器中按 Ctrl-j，无需先输入触发词
  {replacement: () => "\\operatorname{$0}$1", options: "m", triggerKey: "Ctrl-j"}
]
```

### 模板语法

| 写法 | 含义 |
| --- | --- |
| `$0`、`$1`、`$2` | 按编号从小到大导航，**`$0` 是第一个位置** |
| `${0:x}` | 编号为 0、默认内容为 `x` 的停靠点 |
| 重复的相同编号 | 原生源码框中联动编辑 |
| `[[0]]`、`[[1]]` | 正则的第一、第二个捕获组，不是整个匹配 |
| `[[name]]` | 名为 `name` 的正则捕获组 |
| `${VISUAL}` 或 `[[selection]]` | 选中的文本；显式选区模式可使用 `v` |

JavaScript 字符串中的 LaTeX 反斜杠要写成 `\\`。动态 `replacement` 接受字符串触发词或正则匹配结果，须同步返回字符串；返回 `false` 可跳过当前匹配，不支持异步函数。函数报错后，该规则在当前编辑器内暂时隔离；修改源文本或重新打开公式可重试。

### options 与其他字段

| 选项 | 作用 |
| --- | --- |
| `m` | 在行级公式和公式块中启用，文本宏内部除外 |
| `M` | 仅公式块 |
| `n` | 仅行级公式 |
| `T` | 文本宏内部；可用 `MT` / `nT` 限制公式类型 |
| `t` | 上游正文模式；本插件正文仅专门适配 `mk` / `dm` |
| `A` | 自动展开；无 `A` 时通常按 Tab 展开 |
| `r` | 正则触发词，也可将 `trigger` 直接写为正则字面量 |
| `w` | 要求触发词两侧满足设置中的单词边界 |
| `v` | 选区片段 |

`description` 会显示在片段速查中；`priority` 用于调整规则匹配优先级。还支持 `flags`、`triggerKey`、`triggerAfter`、`includedMacros`、`excludedMacros` 和 `excludedEnvironments`。`triggerAfter` 匹配光标后的内容，匹配内容也包含在替换范围里。

### 触发器变量

在独立的 **Snippet 变量** 文本框中定义可复用的正则片段：

```js
{
  "${GREEK}": "alpha|beta|gamma|delta|theta|lambda|sigma|omega",
  "${ARROW}": "to|rightarrow|leftarrow|mapsto"
}
```

在 `trigger` 或 `triggerAfter` 中使用 `${GREEK}` 等名字即可展开变量。若希望按正则分支匹配这些字符串，规则需使用正则触发器或 `r` 选项；变量不会自动把普通触发词变成正则。

## 宏区域与触发范围

数学参数、文本参数与颜色等受限参数分别处理。例如 `\textcolor{red}{x}` 的第二个参数仍可输入数学片段，颜色名称不应被改写。

在“文本宏与禁用片段区域”中填写 JSON：

```json
{
  "text": ["mytext", {"name": "caption", "arguments": [1]}],
  "restricted": ["operatorname", {"name": "metadata"}]
}
```

`text` 中的区域使用 `T` 片段；`restricted` 中默认抑制片段。自定义项叠加到内置宏参数规则上。

宏名不含反斜杠，参数编号从 0 开始：字符串 `"foo"` 只匹配第一个参数；`{"name":"foo","arguments":[1]}` 匹配第二个参数；`{"name":"foo"}` 匹配全部参数。这套写法也用于单条片段的 `includedMacros` / `excludedMacros`。

`includedMacros` 按最内层宏与参数限定匹配；显式排除仍然优先。默认把 `operatorname` 的首参数设为自定义受限区域，需要时可从该设置中移除这一项。

## 设置与保存

| 设置组 | 可以调整什么 |
| --- | --- |
| 功能开关 | 自动片段、手动片段、分数、矩阵、Tab 跳出、选区片段 |
| 输入行为 | 输入法组合保护、行级片段尾随空格、单词分隔符、递归次数 |
| 分数 | 分数命令、扫描终止字符、排除区域 |
| 矩阵 | 可识别的环境与宏 |
| 括号与跳出 | 闭合符号、只在边界退出、自动放大命令与空格 |
| 自定义 | 完整片段源、变量源、宏区域和 9 项快捷键 |

递归次数默认是 `0`，即关闭递归；设为正整数后，一次展开可继续触发自动规则，次数受设置限制。

点击设置确认后，配置先校验语法、结构和正则，再保存。只有保存成功才切换运行配置；失败时继续使用上一次配置并提示。连续保存按顺序处理。输入法保护建议保持开启，重复停靠点也会等组合提交后再联动。

## 从 0.2.x 升级

- **自定义片段保留原样。** 仅完全未改动的旧内置源会更新 `beg`，使行级公式使用空格、公式块使用换行。不要为了获取新片段而直接覆盖自己的配置。
- **文本宏使用 `T`。** 如果曾按旧版说明用 `t` 在 `\text{}` 中展开，请手动改为 `T`。`t` 表示上游正文模式。
- **检查宏参数排除规则。** 字符串宏名现在仅匹配第一个参数；需要全部参数时，使用不带 `arguments` 的对象形式。
- **快捷键缺失项补默认值。** 如有冲突，可单独改键或禁用。
- **迁移 Obsidian 配置时先检查 API。** 支持的表达式和模板可以复用，依赖 `view` / `ctx`、CodeMirror、LuaSnip 或模块导入的代码需要改写。

原生源码框的停靠点从 `$0` 开始，而不是把 `$0` 当作最后退出位置。新写模板时应把分子放在 `$0`、分母放在 `$1`，末尾位置放在 `$2`。

## 编辑器与兼容范围

| 编辑器 | 适配方式与差异 |
| --- | --- |
| 原生行级 / 公式块源码框 | 直接编辑 LaTeX 文本，支持同编号停靠点联动 |
| 数学增强的 MathLive | 使用原生占位符及导航命令；位置无法精确映射时保留输入或交还原生导航 |
| 桌面、移动、浏览器前端 | 在可识别的公式编辑器中接入；触屏端可按需要改键 |

源码框优先使用浏览器编辑事务保留撤销历史，撤销/重做后会清理旧停靠点，不恢复历史停靠点。前端不支持该编辑命令时回退为文本修改，回退路径不保证原生撤销历史。

本插件以 Obsidian LaTeX Suite 1.14.1 的可移植行为为对照，保留自己的定制片段集。Conceal、彩色括号、美元符号着色、CodeMirror `context` / `includedPaths`、LuaSnip 节点 API、片段文件监听和完整模块导入尚未适配。反向退出会关闭思源公式面板，不保证正文光标落在公式之前。

自动化和独立 Chromium 夹具的覆盖不等同于所有思源前端与真实 MathLive 的实机验收，具体范围见[对齐记录](../UPSTREAM_ALIGNMENT.md#验证边界)。

## 常见问题

### 输入了触发词，却没有展开

先确认插件和对应功能已启用，并且光标在公式编辑器中。检查当前规则是否需要 Tab、是否限定行级或公式块、是否处于文本宏或排除区域。输入法组合尚未提交时，默认暂不展开。最后在片段速查中搜索触发词，确认它存在于已保存配置中。

### frac 或 mat 为什么不展开

默认分数入口是 `x/` 和 `//`，矩阵入口是 `pmat` / `bmat`。`frac` 是本指南的自定义示例，需自行添加；默认没有名为 `mat` 的片段。

### Tab 换列或跳出的行为与预期不同

先检查是否仍有活动停靠点，或光标是否在单元格里的括号、分数参数中。再检查动作是否改键、被禁用，以及宿主是否占用了按键。源码框与 MathLive 的导航细节有所不同。

### 设置保存后没生效

检查是否出现格式校验或保存失败提示。确认修改的是片段源还是变量源，并点击确认保存。保存失败不会切换到新配置；修正后重试即可。

### 某条动态片段突然不再工作

报错规则会在当前编辑器内隔离并提示一次，其他规则仍可使用。检查函数能否同步返回字符串或 `false`，修复源文本后保存，或重新打开公式再试。

### 集市仍然显示旧版本

集市索引与 GitHub Release 存在同步间隔。稍后重启思源刷新，或下载最新 Release 的 `package.zip` 手动安装。安装目录中应直接出现 `plugin.json`，避免多套一层目录。

## 开发验证

在项目目录执行 `npm ci` 后：

| 命令 | 用途 |
| --- | --- |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm test` | 单元和回归测试 |
| `npm run check` | 类型检查、测试、生产构建 |
| `npm run package` | 构建并生成可安装的 `package.zip` |
| `npm run benchmark` | 固定工作负载的片段匹配微基准，不代表思源整体输入延迟 |

运行 `npm exec vite -- --host 127.0.0.1 --port 4175`，打开 `http://127.0.0.1:4175/tests/browser-harness.html`，可单独检查源码框与片段速查。此夹具不连接思源数据，也不代表真实 MathLive 实例。
